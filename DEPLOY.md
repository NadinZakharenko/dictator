# Dictator: автозапуск и модели

Приложение работает внутри сессии пользователя. Не запускайте его от администратора: ввод из обычного процесса в повышенное окно не доходит, окна ZCode обычные.

## Куда копировать

Соберите `build.ps1`. Готовая папка появляется в `C:\AI\VoiceAgent\dist\Dictator`. На сервер копируйте её целиком. Python на сервере не нужен. Модель в exe не входит.

## Общая папка моделей

По умолчанию модели лежат в `%ProgramData%\Dictator\models`.

- При старте приложение смотрит туда. Если выбранной модели нет, оно один раз скачивает её с Hugging Face. Аудио никуда не отправляется.
- На сервере достаточно, чтобы первый пользователь скачал модель, либо скопируйте уже заполненную папку с машины, где она уже есть. Остальным пользователям папка должна быть доступна на чтение.
- Если создать папку не удалось, в трее будет сообщение. Тогда в конфиге укажите другой путь в поле `model_dir` и выберите «Перечитать».

## Автозапуск

В меню иконки включите «Автозапуск». Это запись `Dictator` в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` текущего пользователя. Тот же пункт её удаляет.

## RDP

В клиенте удалённого рабочего стола включите перенаправление записи звука: локальные ресурсы, записать с этого компьютера. Без этого микрофон до сессии не доходит.

## Конфиг

Файл: `%APPDATA%\Dictator\config.json`. Журнал: `%APPDATA%\Dictator\dictator.log`.

Пункт «Открыть конфиг» открывает файл в Блокноте. «Перечитать» применяет его без перезапуска.

Поля, которых нет в меню трея:

- `hotkey` — по умолчанию `f9`. Клавиша глотается и не попадает в активное окно.
- `silence_seconds` — пауза после речи, после которой запись останавливается. По умолчанию `1.5`.
- `initial_prompt` — подсказка терминов для распознавателя. Пустая строка выключает её.
- `device` — имя устройства записи из журнала или `null` для устройства по умолчанию.
- `model_dir` — папка моделей. Пустая строка означает `%ProgramData%\Dictator\models`.
- `insert_mode` — `unicode` печатает текст сразу и не трогает буфер обмена. `paste` вставляет через Ctrl+V и возвращает в буфер только прежний текст.
- `vad_threshold` — порог речи Silero от 0 до 1, по умолчанию `0.5`.

Переводы строк в распознанном тексте заменяются пробелом, чтобы Enter не отправил промпт сам.

В меню трея переключаются режим удержания и переключения, модель `base` или `small`, язык «Русский» или «Авто», звук и автозапуск.
